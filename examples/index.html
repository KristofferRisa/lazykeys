lazykeys demo — press Space and wait, ? for the map, :q to leave.

A LazyVim-shaped keyboard for any page

This page loads dist/lazykeys.iife.js with a plain <script> tag. Try j/k, 5j, gg, G, 40%, } and {.

Leader and which-key

Press Space: a panel lists every key that can follow it, with +name for the ones that open a further menu. Spaceu narrows it to the toggles. This demo adds its own group, Spaced +demo.

Link hints

Press f to label every link in view and type a label to follow it; F opens it in a new tab. A few links to try: hints, search, sidebar, LazyVim, which-key.nvim, flash.nvim.

Search

Press / and type keyboard. Matches are painted with the CSS Custom Highlight API — the page's DOM is never touched. n and N walk them; :noh stops painting.

The keyboard is the fastest pointer you own. A keyboard layer that answers questions is a keyboard layer for everyone, not only for the person who wrote it.

The sidebar

Spacee opens the explorer — this demo feeds it a made-up site. Tab walks the sources: explorer, outline (go), buffers (Space,) and settings (Spaceuo).

The command line

: opens a floating line. Tab completes. Try :help, :set, :set scroll=140, :set nostatusline, :set leader=,, :checkhealth, :Lazy, :messages, :set nolazy, and this demo's own :hello {name}.

Insert mode

While the caret is in a field every key belongs to it. gi jumps in, Esc leaves.

Settings

Everything is one schema, stored under localStorage["lazykeys-demo:settings"]. Reload the page: what you changed stays changed.

The end. gg takes you back to the top.
